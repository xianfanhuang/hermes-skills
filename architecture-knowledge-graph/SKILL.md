# 交互式架构知识图谱构建

将任意多层、多组件系统架构转化为可拖拽、可缩放、点击查看详情、高亮关联的 Web 端交互式知识图谱。

## 触发条件

当用户需要：
- 将系统架构可视化
- 生成交互式架构图谱
- 创建可分享的知识图谱 HTML
- 制作技术文档中的架构图

## 核心能力

| 能力 | 说明 |
|------|------|
| **架构可视化** | 将文本/图表架构描述转为可视化图谱 |
| **交互式浏览** | 支持拖拽、缩放、点击查看详情 |
| **关联高亮** | 点击节点高亮其直接邻居 |
| **自包含输出** | 输出单个 HTML 文件，无需服务器 |

## 使用方法

### 1. 准备架构描述

提供以下信息：
- 系统名称与整体描述
- 核心层/模块及其关系
- 每个节点的详细说明

### 2. 调用技能

```
生成架构知识图谱：
- 系统：XXX系统
- 架构描述：...
- 组件清单：...
```

### 3. 输出结果

生成 `.html` 文件，包含：
- 可交互的架构图谱
- 节点详情面板
- 图例说明

## 技术规格

- **可视化库**: Cytoscape.js (CDN)
- **布局方式**: Preset 手动布局
- **样式**: CSS3 + Flex 响应式
- **输出格式**: 单个 HTML 文件

## 示例输入

```
系统名称：智能交易决策系统

三层架构：
1. 感知层（蓝色）
   - 数据采集模块：实时获取市场数据
   - 特征提取模块：计算技术指标

2. 决策层（橙色）
   - 信号生成模块：产生交易信号
   - 风险评估模块：评估仓位风险

3. 执行层（绿色）
   - 订单管理模块：执行交易指令
   - 监控模块：跟踪订单状态
```
