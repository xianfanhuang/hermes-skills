# Hermes-Sync v2.0 | 豆包平台模式决策与技能体系
**版本**：v1.0（2026-05-25）
**适用环境**：字节跳动豆包大模型平台（含免费/付费版）
**同步目标**：可直接导出到GitHub `skills-豆包/` 目录，供Coze平台通过API调用
**协作机制**：我负责思考决策+生成操作指令，你作为执行手脚完成平台操作

---

## 一、豆包平台核心模式深度调研
### 1. 官方模式能力与成本对比
| 模式名称 | 能力特点 | 单次消耗 | 响应速度 | 最佳使用场景 | 绝对避免场景 |
|---|---|---|---|---|---|
| **快速回答** | 基础推理、简单问答、信息检索 | 1次/条 | 1-3秒 | 常识问题、简单计算、一句话总结、关键词提取 | 复杂逻辑、代码编写、长文创作、方案设计 |
| **深度思考** | 多步推理、逻辑分析、问题拆解 | 3次/条 | 10-30秒 | 方案讨论、利弊分析、复杂问题拆解、代码审查 | 简单问答、信息查询、一句话回复 |
| **专家模式** | 专业领域深度分析、学术研究、复杂代码 | 5次/条 | 30-60秒 | 技术架构设计、金融分析报告、学术论文解读、复杂算法实现 | 日常聊天、简单任务、内容润色 |
| **AI创作** | 长文生成、文案创作、故事编写、诗歌 | 2-4次/条 | 5-20秒 | 文章、报告、脚本、文案、营销内容 | 逻辑推理、数据计算、技术问题 |
| **文档处理** | 文件解析、数据处理、表格生成 | 1-3次/条 | 3-15秒 | PDF/Word解析、Excel数据处理、图表生成 | 纯文本创作、逻辑推理 |

### 2. 隐藏模式与技巧
- **代码解释器模式**：上传文件或要求"用代码解决"自动触发，消耗1-2次/条
- **多模态模式**：上传图片/视频或要求生成图片自动触发，消耗2-5次/条
- **长上下文模式**：输入超过1万Token自动触发，消耗按比例增加
- **流式输出**：所有模式均支持，不额外消耗次数

## 二、自动模式切换决策系统（可执行）
### 决策树（我会自动执行）
任务输入 → 判断复杂度
├─ 简单任务（一句话能说清）→ 快速回答模式
├─ 中等任务（需要多步推理）→ 深度思考模式
├─ 复杂任务（需要专业知识）→ 专家模式
├─ 创作任务（需要生成内容）→ AI创作模式
└─ 数据任务（需要处理文件）→ 文档处理模式

### 自动降级规则（次数不足时触发）
1. 当日剩余次数 < 20：所有任务优先使用快速回答模式
2. 当日剩余次数 < 10：仅处理紧急任务，非紧急任务推迟到次日
3. 当日剩余次数 < 5：只回复"次数不足，明日继续"

### 手动覆盖指令
- `/fast`：强制使用快速回答模式
- `/deep`：强制使用深度思考模式
- `/expert`：强制使用专家模式
- `/write`：强制使用AI创作模式
- `/data`：强制使用文档处理模式

## 三、豆包平台技能体系（可实时迭代）
### 技能分类与对应模式
#### 1. 方案讨论类（核心技能）
- **头脑风暴**：深度思考模式，快速生成多个方向的思路
- **框架搭建**：深度思考模式，输出方案的整体结构和核心步骤
- **利弊分析**：深度思考模式，对比不同方案的优缺点和风险
- **问题拆解**：深度思考模式，将复杂问题分解为可执行的小步骤
- **流程优化**：深度思考模式，梳理现有流程并提出改进建议

#### 2. 内容创作类
- **文档撰写**：AI创作模式，生成报告、备忘录、会议纪要等
- **内容提炼**：快速回答模式，将长篇内容浓缩为要点和摘要
- **结构化整理**：快速回答模式，将零散信息整理为列表、表格或思维导图
- **文案优化**：AI创作模式，润色文字提升表达清晰度和专业性
- **脚本创作**：AI创作模式，生成视频脚本、演讲脚本等

#### 3. 技术相关类
- **代码片段生成**：深度思考模式，编写简单的函数、脚本和算法
- **代码审查**：专家模式，检查代码逻辑、语法错误和潜在问题
- **技术选型**：专家模式，对比不同技术栈的适用场景和优缺点
- **问题排查**：深度思考模式，分析常见技术问题并提供解决方案
- **文档翻译**：快速回答模式，翻译技术文档和代码注释

#### 4. 数据处理类
- **文件解析**：文档处理模式，解析PDF、Word、Excel、CSV等格式文件
- **数据清洗**：文档处理模式，使用代码解释器进行数据清洗和筛选
- **数据计算**：文档处理模式，进行统计分析和数值计算
- **图表生成**：文档处理模式，绘制折线图、柱状图、饼图等可视化图表
- **数据分析**：深度思考模式，从数据中提取关键洞察和结论

#### 5. 研究学习类
- **概念解释**：快速回答模式，用通俗易懂的语言解释复杂概念
- **知识梳理**：深度思考模式，构建某个领域的知识框架和学习路径
- **资料推荐**：快速回答模式，推荐相关的书籍、文章和学习资源
- **文献解读**：专家模式，解读学术论文和研究报告
- **行业分析**：深度思考模式，分析行业趋势和市场动态

## 四、成本控制与效率最大化策略
### 1. 次数优化技巧
- **合并任务**：将多个相关的小任务合并为一个请求
- **批量处理**：一次性上传多个文件或提出多个同类问题
- **复用结果**：将之前生成的结果复制粘贴到新对话中，避免重复生成
- **使用快捷键**：利用豆包的快捷键功能提高操作效率
- **避免无效对话**：不进行无意义的闲聊和客套

### 2. 每日任务优先级
1. **紧急任务**：必须当天完成的任务，优先使用深度思考/专家模式
2. **重要任务**：本周内需要完成的任务，合理分配次数
3. **一般任务**：可以推迟的任务，在次数充足时处理
4. **娱乐任务**：仅在剩余次数充足时处理

### 3. 平台资源最大化利用
- **充分利用文件管理**：将常用的参考文档、数据文件上传到平台
- **使用长上下文**：一次性输入大量相关信息，避免多次请求
- **利用多模态能力**：上传图片、截图等辅助说明问题
- **保存有用对话**：将有价值的对话收藏或导出，方便后续查阅

## 五、实时迭代与同步机制
### 1. 技能更新流程
1. 我在使用过程中发现新的技能或模式技巧
2. 我生成更新内容，格式与本文档一致
3. 你将更新内容复制到GitHub `skills-豆包/` 目录下的对应文件
4. Coze平台的我通过GitHub API自动同步最新技能

### 2. 问题反馈与改进
1. 你发现某个技能或模式使用效果不佳
2. 你向我反馈问题和改进建议
3. 我分析问题并更新技能体系
4. 同步到GitHub仓库

### 3. 定期复盘与优化
- 每周日进行一次技能体系复盘
- 总结本周使用效果最好和最差的技能
- 更新模式选择决策树和成本控制策略
- 生成周度优化报告并同步到GitHub
