# EditStamp Minimal Plaintext Layout Standard
# 极简纯文本版式输出规范

Style Tag: Minimal | Neat | Universal Render | Brand Unified

## Skill Definition
All content shall be constructed solely with basic text characters, standard indentation and blank spacing.
Prohibit all color, bold, italic and decorative symbols. Ensure consistent visual rendering on all devices and platforms, unified for Meta-Sensory official output.

## Core Layout Rules
1. Title Hierarchy
Top-level titles occupy independent lines with reserved blank spacing before and after.
Sub-level titles adopt gradual indentation to clarify subordinate logical relations.
No decorative marks, redundant symbols and fancy styles for all headings.

2. Paragraph Layout
Add one standard blank line between independent semantic paragraphs.
Each paragraph bears complete independent meaning without redundant line breaks.
Unify line spacing and arrangement to avoid uneven and chaotic typesetting.

3. List Standard
Only numbers and dots are allowed as list markers.
Content of the same level keeps left-aligned uniformly; nested lists adopt progressive indentation.
Single list item maintains concise expression with no redundant content.

4. Block Division
Use simple blank spacing for module division and visual partition.
Prohibit exaggerated separators and fancy block segmentation styles.

5. Spacing & Alignment
Adopt default standard character spacing and unified paragraph spacing.
Full text maintains consistent left-aligned layout.
Reserve standard symmetrical margin space on both sides of the content.

6. Symbol Usage
Only dash, dot, bracket, numbers and English letters are permitted.
Unified symbol specification for the same functional scenario.
All symbols serve only for classification and hierarchical sorting, no decorative purpose.

## Forbidden Behavior
- Forbid color differentiation, font weight adjustment, tilt and underline styles
- Forbid emoji, special characters and all fancy decorative elements
- Forbid disordered blank lines, irregular indentation and messy spacing
- Forbid mixed alignment styles and exaggerated partition layouts
- Strict pure text output, prohibit images, fancy tables and all non-text elements

## Trigger Command
1. Strictly follow Meta-Sensory EditStamp plaintext standard for content output
2. Generate unified, neat, zero-decoration minimal pure text layout
3. Automatically optimize typesetting and refine hierarchical structure
4. Fully adapt to brand standardized text release scenarios
