## 📋 工作流程

### 每日扫描流程

```
08:00 早盘扫描
  ├── 扫描隔夜新闻 (美股收盘后事件)
  ├── 扫描亚洲市场动态
  └── 生成早盘信号

12:00 午盘扫描
  ├── 扫描午间新闻
  ├── 更新技术面信号
  └── 生成午盘信号

18:00 晚盘扫描
  ├── 扫描欧洲市场动态
  ├── 扫描财报/公告
  └── 生成晚盘信号

22:00 夜盘扫描
  ├── 扫描美股收盘数据
  ├── 当日信号复盘
  └── 更新模拟持仓
```

### 信号生成流程

```
1. 信息收集 (5分钟)
   ├── 搜索新闻关键词
   ├── 获取财报数据
   └── 抓取社区讨论

2. 技术分析 (3分钟)
   ├── 计算技术指标
   ├── 识别图表模式
   └── 确定关键价位

3. 基本面分析 (3分钟)
   ├── 评估财务健康
   ├── 行业对比分析
   └── 估值判断

4. 情绪分析 (2分钟)
   ├── 新闻情感分析
   ├── 社区热度评估
   └── 恐惧贪婪指数

5. 综合评分 (2分钟)
   ├── 多因子加权
   ├── 信号强度计算
   └── 风险评估

6. 信号输出 (即时)
   ├── 生成信号报告
   ├── 记录到数据库
   └── 推送给 Captain (可选)
```

## ⚙️ 配置参数

### 技术面参数
| 指标 | 参数 |
|------|------|
| RSI | 周期14, 超买70, 超卖30 |
| MACD | 快线12, 慢线26, 信号9 |
| 均线 | MA5, MA10, MA20, MA50, MA200 |
| 布林带 | 周期20, 标准差2 |

### 基本面参数
| 指标 | 权重 |
|------|------|
| PE/PB | 20% |
| ROE | 20% |
| 营收增长 | 25% |
| 利润增长 | 25% |
| 现金流 | 10% |

### 情绪面参数
| 来源 | 权重 |
|------|------|
| 新闻情绪 | 40% |
| 社区热度 | 30% |
| 恐惧贪婪指数 | 30% |

| 因子 | 权重 |
|------|------|
| 技术面 | 40% |
