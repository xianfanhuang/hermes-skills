# 交易SOP - 自动化运行体系

## 🎯 目标
盘前→盘中→盘后全流程自动化，一个系统统一运行

---

## 📋 流程概览

```
盘前 (08:00-09:30)
  ├─ 持仓检查
  ├─ 缠论分析
  ├─ 策略确定
  └─ 止损止盈设置

盘中 (09:30-16:00)
  ├─ 实时监控 (每5分钟)
  ├─ 信号触发
  ├─ 下单执行
  ├─ 订单状态检查
  └─ 止损止盈执行

盘后 (16:00-18:00)
  ├─ 平仓检查
  ├─ 盈亏统计
  ├─ 交易记录整理
  └─ 反思和优化
```

---

## 🔧 自动化运行

### Cron Jobs
- 盘前扫描: 08:00
- 盘中监控: 每5分钟 (09:30-16:00)
- 盘后总结: 16:30
- 记忆更新: 每小时

### 运行方式
```bash
# 盘前
python3 engine.py --pre-scan

# 盘中
python3 engine.py --run --interval 300

# 盘后
python3 engine.py --post-summary
```
