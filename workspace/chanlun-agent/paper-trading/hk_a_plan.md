## 交易规则

### 开仓条件（必须同时满足）
1. **日线方向**明确（上涨笔/下跌笔）
2. **30分钟出现缠论买点**（一买/二买/类二买/背驰）
3. **买点强度 >= 0.5**
4. **5分钟确认信号**（底分型/向上笔）

### 风控参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 单笔风险 | 2% | 最大亏损占本金比例 |
| 日度风险 | 6% | 当日最大亏损上限 |
| 连续亏损熔断 | 3笔 | 暂停60分钟 |
| 止损方式 | 移动止损 | 盈利后上移止损位 |

### 费用参考（Tiger）
- **港股**: 0.06%（平台费）+ 0.1%（印花税）+ 其他 = ~0.16%
- **A股**: 0.03%（平台费）+ 其他 = ~0.06%

## 执行流程

### 开盘前 (09:00)
1. 获取所有品种日线数据
2. 分析日线方向（上涨/下跌/盘整）
3. 筛选出日线方向明确的品种

### 早市 (09:30-12:00)
1. 每30分钟扫描一次30分钟级别买点
2. 出现买点信号 → 进入观察列表
3. 5分钟确认 → 计算仓位/止损 → 模拟下单
4. 持仓监控 → 移动止损/止盈

### 午间休市 (12:00-13:00)
1. 复盘早市交易
2. 更新日线/30分钟结构
3. 准备午市观察列表

### 午市 (13:00-15:00/16:00)
1. 继续监控买卖点
2. 处理持仓（止损/止盈/移动止损）
3. 避免收盘前15分钟新开仓

### 收盘后
1. 生成当日交易报告
2. 更新收益曲线
3. 复盘分析
