## 🔴 风险警告

### 关键风险点

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 胜率低于70% | 周收益无法达到61% | 重新优化策略 |
| 连续止损3次 | 当日被迫停止 | 严格止损能避免 |
| 单笔超过5%仓位 | 风险失控 | 永远不超过 |
| 持仓过夜 | 时间价值衰减 | 禁止持仓过夜 |
| 追涨杀跌 | 胜率下降 | 严格按信号交易 |

### 爆仓风险

**什么情况下可能爆仓？**
- 连续5次止损（-12.5%）
- 单笔杠杆超过20倍
- 不设止损

**如何避免爆仓？**
- 严格设置止损
- 控制仓位比例
- 连续3次止损后停止交易

## 🔧 常见问题

### Q1: 为什么期权交易需要70%胜率？

**A:** 期权有时间价值衰减，每天损失约1-3%。如果胜率低于70%，时间价值衰减会吃掉大部分利润。70%胜率是期权交易长期盈利的最低要求。

### Q2: 每单盈利50%是否太高？

**A:** 使用10倍杠杆，标的需要5%波动即可达到50%盈利。这在日内交易中是可以实现的，但需要精准的时机把握。

### Q3: 连续亏损3次后怎么办？

**A:** 立即停止当日交易，完整复盘分析原因。可能是市场环境不适合、策略有缺陷、或者交易心态有问题。次日开盘前必须解决问题。

### Q4: 如何提高胜率？

**A:**
1. 严格执行入场规则，不要在信号不明确时开仓
2. 每笔交易前仔细检查所有条件
3. 复盘每一笔交易，分析成功和失败的原因
4. 不要追涨杀跌，要等待明确信号
5. 控制情绪，保持理性

### Q5: 如果连续一周胜率低于60%怎么办？

**A:** 暂停交易，重新评估策略。可能是市场环境变化，或者策略需要调整。模拟测试至少1周，确认有效后再实盘。
