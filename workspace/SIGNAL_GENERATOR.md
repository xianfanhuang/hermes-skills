# 交易信号生成器 - Signal Generator

## 📋 信号生成流程

### Step 1: 信息收集 (5分钟)

#### 1.1 新闻扫描
```
关键词:
- 加密货币: BTC, ETH, 加密货币监管, 交易所
- 美股: AAPL, MSFT, NVDA, TSLA, 财报, 美联储
- 宏观: 利率, 通胀, GDP, 就业数据

来源:
- 财经新闻网站 (Bloomberg, Reuters, 财联社)
- 社交媒体 (Twitter/X, Reddit)
- 官方公告 (SEC, 交易所)
```

#### 1.2 财报数据
```
关注指标:
- 营收 (Revenue)
- 净利润 (Net Income)
- 每股收益 (EPS)
- 同比/环比增长
- 指引 (Guidance)
```

#### 1.3 社区情绪
```
监控平台:
- Twitter/X: 关键意见领袖
- Reddit: r/cryptocurrency, r/stocks
- Discord: 项目官方社区
```

---

### Step 2: 技术面分析 (3分钟)

#### 2.1 趋势指标
| 指标 | 买入信号 | 卖出信号 |
|------|---------|---------|
| MA交叉 | 金叉(短期上穿长期) | 死叉(短期下穿长期) |
| MACD | 零轴上方,金叉 | 零轴下方,死叉 |
| RSI | <30 超卖 | >70 超买 |
| 布林带 | 触及下轨 | 触及上轨 |

#### 2.2 支撑/阻力
```
计算方法:
- 前期高点/低点
- 整数关口
- 斐波那契回撤位
- 成交量密集区
```

#### 2.3 图表模式
```
看涨模式:
- 双底 (Double Bottom)
- 头肩底 (Inverse Head & Shoulders)
- 上升三角形 (Ascending Triangle)

看跌模式:
- 双顶 (Double Top)
- 头肩顶 (Head & Shoulders)
- 下降三角形 (Descending Triangle)
```

---

### Step 3: 基本面分析 (3分钟)

#### 3.1 估值指标
| 指标 | 低估 | 高估 |
|------|------|------|
| P/E | <行业平均 | >行业平均 |
| P/B | <1 | >3 |
| PEG | <1 | >2 |

#### 3.2 成长性
```
关注指标:
- 营收增长率 >20%
- 净利润增长率 >15%
- ROE >15%
- 自由现金流为正
```

#### 3.3 财务健康
```
检查项目:
- 资产负债率 <60%
- 流动比率 >1.5
- 利息覆盖倍数 >5
```

---

### Step 4: 情绪面分析 (2分钟)

#### 4.1 新闻情绪
```
分析维度:
- 正面新闻数量 vs 负面新闻数量
- 新闻影响力权重
- 时效性评估
```

#### 4.2 社区情绪
```
指标:
- 讨论热度 (发帖量/互动量)
- 情绪倾向 (看涨/看跌比例)
- 关键意见领袖观点
```

#### 4.3 恐惧贪婪指数
```
来源:
- 加密货币: Alternative.me Fear & Greed Index
- 股市: CNN Fear & Greed Index

解读:
- 极度恐惧 (<25) → 潜在买入机会
- 极度贪婪 (>75) → 潜在卖出信号
```

---

### Step 5: 综合评分 (2分钟)

#### 5.1 评分权重
| 因子 | 权重 | 满分 |
|------|------|------|
| 技术面 | 40% | 40分 |
| 基本面 | 30% | 30分 |
| 情绪面 | 30% | 30分 |

#### 5.2 信号等级
| 分数区间 | 信号 | 颜色 | 建议仓位 |
|---------|------|------|---------|
| 75-100 | 强买入 | 🟢 | 最高5% |
| 60-75 | 买入 | 🟢 | 最高3% |
| 40-60 | 中性 | ⚪ | 观望 |
| 25-40 | 卖出 | 🟠 | 减仓 |
| 0-25 | 强卖出 | 🔴 | 清仓 |

#### 5.3 风险等级
| 等级 | 描述 | 建议止损 |
|------|------|---------|
| 低 | 趋势明确,风险可控 | 5% |
| 中 | 信号一般,需谨慎 | 3-5% |
| 高 | 信号矛盾或市场波动大 | 2-3% |
