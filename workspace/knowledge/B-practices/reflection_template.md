# 交易反思模板

## 反思结构

每次交易完成后自动生成以下结构化反思：

### 1. 结构分析
- 当时的缠论结构（笔/中枢/背驰状态）
- 多级别联立情况
- 分型确认情况

### 2. 决策回顾
- 入场/出场理由
- 仓位大小是否合理
- 止损设置是否恰当

### 3. 归因分析
- 盈利/亏损的主要原因
- 是技术分析准确还是运气成分
- 市场环境因素

### 4. 改进措施
- 下次类似情况如何处理
- 参数是否需要调整
- 策略是否需要优化

## 记录格式

```markdown
## [日期] [品种] [方向] [盈亏%]

### 结构
- 日线趋势: [up/down/neutral]
- 5分钟信号: [bi_buy/bi_sell/zs_buy/zs_sell]
- 中枢位置: [中枢上方/中枢内/中枢下方]

### 决策
- 入场价: $XXX | 出场价: $XXX
- 仓位: XX% | 止损: $XXX
- 信号级别: [L1/L2/L3/L4]

### 归因
- [盈亏主要原因]

### 改进
- [下次改进措施]
```

## 自动追加规则

- 每次平仓后5分钟内自动生成反思
- 连续3笔亏损时触发深度反思
- 每周日生成周度反思汇总
