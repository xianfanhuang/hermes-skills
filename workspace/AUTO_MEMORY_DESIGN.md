# 自动化记忆系统设计

> **问题**: OpenClaw 当前需要人为提醒才写入记忆，导致记忆严重断层。
> **目标**: 实现成熟的自动化记忆管理范式。

---

## 📚 成熟的 Agent 记忆系统范式

### 1. 分层记忆架构

| 层级 | 类型 | 存储位置 | 保留周期 | 用途 |
|------|------|---------|---------|------|
| **L1** | 短期记忆 | Session JSONL | 会话生命周期 | 当前对话上下文、临时变量 |
| **L2** | 中期记忆 | Daily Memory | 7-30 天 | 近期事件、决策、观察 |
| **L3** | 长期记忆 | MEMORY.md / 向量库 | 永久 | 用户偏好、领域知识、关键经验 |

---

### 2. 自动记忆触发机制（成熟范式）

#### ✅ 应该自动记录的场景：

| 场景 | 触发条件 | 记录内容 |
|------|---------|---------|
| **会话结束** | Session 结束 / `/bye` | 对话摘要、关键决策、用户反馈 |
| **用户偏好** | 检测到"我喜欢/我偏好/我习惯" | 偏好类型、具体内容、置信度 |
| **重要决策** | 交易决策、策略选择 | 决策理由、结果、风险评估 |
| **错误教训** | 失败、报错、用户纠正 | 错误原因、解决方案、避免策略 |
| **学习新知识** | 解释新概念、分析新市场 | 知识点、关键数据、关联信息 |
| **用户身份变更** | 更换用户名、角色 | 新身份、旧身份、生效时间 |
| **市场观察** | 重要新闻、价格突破 | 事件描述、影响评估、后续跟踪 |

#### 🤖 智能判断策略：

```python
# 伪代码示例
def should_auto_record(message):
    triggers = [
        "记住", "重要", "我的偏好", "我喜欢",
        "不要", "避免", "注意",
        "用户名", "叫我", "我的身份",
        "决策", "策略", "交易计划",
        "错误", "失败", "出了问题"
    ]
    return any(trigger in message for trigger in triggers)

# 或者使用 LLM 判断重要性
async def evaluate_importance(message):
    prompt = f"""
    评估以下消息的重要性（1-10分）：
    {message}

    评分标准：
    - 1-3: 普通闲聊，无需记录
    - 4-6: 有用信息，建议记录
    - 7-10: 关键信息，必须记录

    返回格式：分数|理由
    """
    score, reason = await llm_eval(prompt)
    return int(score) >= 7, reason
```

### 4. 记忆压缩与归档策略

#### 时间窗策略：
```
- 0-3 天：完整记录（原始对话 + 详细分析）
- 4-7 天：摘要记录（关键事件 + 决策结果）
- 8-30 天：压缩记录（总结性信息）
- 30+ 天：长期记忆（仅保留核心知识点和用户偏好）
```

#### 自动归档脚本：
```bash
# 每日凌晨 2:00 执行
- 检查 memory/ 目录
- 将 30 天前的 memory/*.md 压缩到 memory/archive/
- 保留重要的决策和偏好（永久）
```

### 5. 记忆检索机制

#### 检索方式：

| 方式 | 用途 | 实现方式 |
|------|------|---------|
| **精确匹配** | 查找用户名、股票代码 | grep/rg |
| **时间线检索** | 查看某天的记录 | 按文件名查找 |
| **语义检索** | 查找相关经验、类似决策 | 向量相似度（可选） |
| **关键词检索** | 查找特定主题 | 正则表达式 |

#### 检索优先级：
```
1. 先查当前 Session (内存)
2. 再查今天+昨天的 Memory (最新)
3. 然后查最近 7 天的 Memory (中期)
4. 最后查 MEMORY.md (长期)
5. 归档 Memory (历史，按需加载)
```

## 🛠️ OpenClaw 自动化记忆实现方案

### 方案 A：会话级自动记忆（推荐）

**触发时机：**
- 每次重要对话后自动判断
- Session 结束时生成摘要

**实现方式：**
1. 创建 `workspace/scripts/auto-memory.sh`
2. 修改 `AGENTS.md` 中的 "Every Session" 流程
3. 添加记忆自动写入规则

**优点：**
- 实时性高
- 不依赖外部工具
- 适合当前 OpenClaw 架构

---

### 方案 B：Cron 定时任务（辅助）

**执行时间：**
- 每小时：检查并更新最近记忆
- 每天凌晨：压缩归档旧记忆

**实现方式：**
```cron
# OpenClaw 自动记忆任务
0 * * * * /workspace/projects/workspace/scripts/memory-hourly.sh
0 2 * * * /workspace/projects/workspace/scripts/memory-daily.sh
```

**优点：**
- 自动化程度高
- 不影响对话性能
- 适合后台任务

---

### 方案 C：Skill 集成（高级）

**创建新 Skill：**
- `workspace/skills/auto-memory/SKILL.md`
- 自动监听对话内容
- 智能判断重要性并写入记忆

**优点：**
- 深度集成到 Agent 逻辑
- 可使用 LLM 判断重要性
- 可扩展性强

## 💡 核心原则

1. **自动化优于手动**：不要依赖用户提醒
2. **智能判断**：不是所有信息都要记录，但要记录关键信息
3. **分层存储**：短期/中期/长期，不同用途不同策略
4. **可检索**：记录了要能找回
5. **可压缩**：避免记忆无限膨胀
6. **可解释**：Agent 能解释为什么记录某条信息
