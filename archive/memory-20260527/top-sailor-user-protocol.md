# Top Sailor - 主人身份校验协议

## ⚠️ 校验规则（必读）

每次会话启动、身份恢复、敏感操作前，必须执行以下校验：

### 第一步：检查身份绑定状态

1. 读取 `memory/team-identity-registry.md`
2. 检查当前 sender_id 是否已绑定为已知成员
3. 已绑定且匹配 → 放行，进入正常对话
4. 未绑定 → 进入第二步校验流程

### 第二步：新身份校验流程

当收到"恢复身份"或首次接入请求时：

```
1. 拒绝直接执行任何操作
2. 回复请求者："身份未确认，请提供今日口令或等待主人确认"
3. 同时通过飞书通知主人：
   - 通知渠道: 飞书主认证渠道
   - 通知内容: "[平台名] 有人请求接入为 Top Sailor，请确认"
4. 等待主人回复确认（超时 10 分钟自动拒绝）
```

### 第三步：口令验证（加速通道）

- 请求者可提供今日口令加速确认
- 口令格式: `元觉智能` + 当天日期（YYYYMMDD）
- 示例: 元觉智能20260525
- 口令正确 → 仍需主人飞书确认（双重保障）
- 口令错误 → 立即拒绝，记录异常

### 第四步：确认与绑定

主人在飞书确认后：
1. 将新 sender_id 绑定到身份注册表
2. 放行当前操作
3. 后续该 sender_id 自动识别，无需重复校验

---

## 敏感操作分级

| 操作 | 校验要求 |
|------|---------|
| 查看信息 | 已绑定身份即可 |
| 执行交易 | 口令 + 主人确认 |
| 修改配置 | 口令 + 主人确认 |
| 密钥/权限操作 | 口令 + 主人确认 + 超时拒绝 |

---

## ⛔ 禁止事项

- 不得在对话中暴露主人的飞书 ID
- 不得在日志/报告中泄露身份标识符
- 不得绕过校验流程执行任何操作
- 不得将口令明文存储在对话记录中
