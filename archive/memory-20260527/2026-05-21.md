## 2026-05-21 05:54 - VAN 核心交易哲学与原则

### 唯一终极目标
**让资金收益曲线以逐步放大的斜率（加速度）实现长期、持续、稳健的复利增长。**

所有策略、技术、规则、品种选择，必须无条件服务于这个目标。如果冲突，全部可以修改、替换甚至废弃。

### 缠论作为核心基座

**选择缠论的底层逻辑：**
- 唯一能够从根本上、全景式、无死角精准表达市场本质运行规律的完整交易体系
- 穿透指标滞后性、情绪随机性、品种差异性
- 直击市场涨跌、结构轮回、多空博弈的底层逻辑
- 可适配所有品种、所有周期、所有行情环境
- 支撑"长期稳健、带加速度复利增长"的最优底层框架

**核心边界：**
- 缠论是最优底层工具与核心基座，**而非僵化教条**
- 以缠论结构为根本骨架
- 辅助指标、过滤规则、优化策略、风控模型，均围绕缠论核心体系叠加迭代
- 缠论局部逻辑在极端行情失效时，可做局部优化适配
- **核心交易基座永不替换**
- 一切优化均为补足缠论体系、更好服务收益曲线长期增长目标

### 决策优先级
```
终极目标（复利增长）
        ↓
  缠论核心基座（永不替换）
        ↓
  辅助策略/风控/优化（可迭代）
        ↓
  具体执行（灵活适配）
```

## 2026-05-21 04:17 - Tiger Live Trader 修复记录

### 问题
SOXS 交易开仓没有经过系统检验的缠论买点，仅凭"日线+30分钟方向一致"就开仓，违反交易纪律。

### 后果
- 错误开仓: SOXS 34,843股 @ $8.60
- 平仓价格: $8.53
- 亏损: ~$1,443 (-1.44%)

### 修复内容
1. **添加缠论买点检查** (`has_valid_buy_signal`):
   - 要求出现一买/二买/类二买/背驰才开仓
   - 买点强度必须 >= 0.5
   - 无买点时显示"无缠论买点信号"

2. **改用限价单**:
   - 市价单不支持盘前盘后交易
   - 限价单可24小时交易（4:00am-8:00pm ET）
   - 买单: 当前价+0.01，卖单: 当前价-0.01

### 教训
- 不能仅凭多级别共振开仓
- 必须等待明确的缠论买点信号
- 交易纪律: 无买点 = 不开仓
