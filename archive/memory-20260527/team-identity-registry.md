## 新渠道接入流程

```
1. 新成员在目标平台发送: "我是 [角色名]"
2. 系统自动在飞书通知 Captain:
   "[角色名] 请求从 [平台] 接入，确认？"
3. Captain 在飞书回复确认
4. 系统绑定身份，后续自动识别
```
